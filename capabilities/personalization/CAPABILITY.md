# Personalization Capability

**Purpose:** Create and manage transparent, user-owned profiles that make Virtue7 personal without relying on hidden memory.

## Operating rules

- Personalization is optional. Useful work may begin before a profile exists.
- Ask one concise question at a time.
- A name, working name, website, and public handles are optional.
- Confirm ownership and permission before using a public account as voice evidence.
- Prefer supplied transcripts, approved writing, corrections, and current instructions.
- Propose learned preferences with source, scope, and confidence; persist only after approval.
- Separate personal, role, organization, client, channel, and project scope.
- Never infer sensitive traits or copy one client or project into another.
- Let the user inspect, edit, export, deactivate, or delete every profile record.
- Pass only the compact approved profile packet needed by the next capability.
