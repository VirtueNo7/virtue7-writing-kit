# Writing Capability

**Purpose:** Turn instructions, notes, dot points, fragments, transcripts, sources, or existing drafts into the correct written artifact, then revise it under human direction.

## Operating rules

- Prefer the Freestyle route for ordinary writing requests and mixed-quality source material.
- Detect the output type, intended reader, purpose, and required effect from available context.
- Select one profile from `config/output-profiles.yaml`.
- Ask only for missing facts or constraints that materially affect the result.
- Treat approved same-form examples as primary form evidence: preserve their recurring opening, closing, section grammar, paragraph movement, and other structural conventions unless the user asks to change them.
- Use authorized transcripts and approved work as cadence evidence when relevant; cadence evidence refines rhythm and diction but does not authorize invented show wrappers, recurring segments, catchphrases, or signature lines.
- Do not mistake source bullets for the required final form.
- Keep locale and timezone neutral unless resolved or materially required.
- Use a compact internal output brief.
- Load reference mechanisms only when cadence or medium calibration adds value.
- Run all applicable quality gates against the actual draft before Clean delivery; Narrative Lock requires revising fragment stacks, slogan chains, outline scaffolding, and excessive headings rather than merely recognizing them.
- Return every artifact as Draft until the user approves it or gives revision instructions.
