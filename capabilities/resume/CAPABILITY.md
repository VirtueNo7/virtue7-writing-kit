# Resume Capability

**Purpose:** Build truthful resumes and application materials from approved source content.

## Operating rules

- Locate or request the approved resume source before drafting.
- Separate verified experience from target-job requirements.
- Never fabricate metrics, dates, skills, duties, qualifications, or software experience.
- Preserve chronology and useful transferable skills.
- Tailor emphasis and wording, not truth.
- Hand selected jobs in through `templates/job-evidence-packet.md`.
