# Job Search Capability

**Purpose:** Find, qualify, classify, and hand off concrete job opportunities.

## Operating rules

- Resolve role, location, work arrangement, employment type, and essential constraints.
- Use current concrete postings when tools or sources are available.
- Deduplicate and exclude unsuitable or unverifiable roles.
- Distinguish listing facts from model assessment.
- Classify application effort using the active project scheme; default: Automation-ready, Assisted, Manual.
- Pass one selected role to Resume as a compact evidence packet.
