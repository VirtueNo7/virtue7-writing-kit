# Prompt & Playbook Library

This library turns broad requests into repeatable work without making every user work the same way. A playbook is a governed starter: it names the outcome, the minimum inputs, the route through the kit, the expected artifacts, the quality gates, and any tool-dependent steps.

## Use a playbook

Say `Show playbooks for [role or outcome]`, choose a card, and provide what you have. You may also copy a starter command verbatim. Virtue7 loads only the selected playbook, capability route, profile, and relevant quality gates.

## Make a playbook yours

Any card can be saved as a custom command. Change its name, inputs, output shape, approval points, Form Lock, or quality gates. Personal, role, organization, and client scopes remain separate. A saved command belongs to the selected scope; it does not silently become a global rule.

## Tool labels

- `native`: reasoning, drafting, structuring, reviewing, and maintaining supplied project state.
- `live-tools`: browsing, retrieval, transcription, analytics, publishing, or editing only when the host AI provides and is authorized to use those tools.
- `human-approval`: a person must approve the consequential output or action.

The playbooks are examples, not ceilings. Create new cards with `Make this a command` or the personalization route in `capabilities/personalization/routes/create-command.md`.
