# Release Notes — v0.3.0

## First Public GitHub Release

Virtue7 Writing Kit v0.3.0 is a lightweight, white-label writing and project-output system that can begin with a direct request, rough notes, dot points, fragments, transcripts, sources, or an existing draft. Users do not need to understand the internal architecture before working.

## Practical workflow

The kit supports a complete human-governed lifecycle:

**Input → Draft → Revision → Approval → Export or Release**

A user can request an opening statement, essay, chapter, legal document, resume, research brief, content asset, project continuation, or review task. After production, the artifact remains a draft until the user approves it. Natural-language revision instructions are authoritative and preserve unaffected material.

## Highlights

- Freestyle Writing from notes, dot points, fragments, transcripts, sources, and direct instructions;
- adaptive output profiles with profile-specific structure rules;
- user-owned voice calibration from available transcripts and approved work;
- precise revision commands and explicit human approval;
- file-format selection independent of content profile;
- on-screen, Markdown, TXT, DOCX, PDF, and HTML delivery targets when host tools permit;
- location-neutral language, spelling, units, date, jurisdiction, and timezone handling;
- Resume, Job Search, Content Creator, Research, Legal, Continuation, and Review capabilities;
- technique-led reference packets with style-distance safeguards;
- isolated Virtue№7 reference implementation and semantic round-trip demo;
- three-file lean boot with one-capability loading discipline;
- executable validation, regression fixtures, manifest integrity, and ZIP hygiene checks.

This release freezes the initial open-source feature surface around a practical goal: transform human material and instructions into governed, revisable, approvable, and exportable work without surrendering control to the model.
