# Semantic Round-Trip Test

For each projection:

1. Compress the output into one paragraph, one operational sentence, one decision line, and one pair.
2. Compare direction, definitions, mechanism, boundaries, and reader value with `units/pride-to-humility.yaml`.
3. Block the projection if it converts humility into obedience, pride into confidence, correction into shame, or private reflection into judgement of others.
4. Record omissions that remove a decisive qualification even when every included sentence is accurate.

A valid output may change length, voice, sequence, character, and medium. It may not reverse the underlying meaning.
