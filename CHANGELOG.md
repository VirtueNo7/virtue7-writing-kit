# Changelog

## 0.5.0 - 2026-08-09

- Replaced the broad first-run capability menu with a compact three-mode boot: Chat, Create content, and Automate a task.
- Added compiled route and profile packets for minimum-sufficient runtime loading.
- Added canonical artifact, approval, tool-receipt, taxonomy, and gate controls with deterministic validation.
- Added paired profile fixtures and complete worked examples across every shipped route.
- Added the `spoken_argument` output profile.
- Strengthened prose-led writing with an explicit pseudo-list guard: successive short standalone points must be developed into continuous prose or, where list structure is permitted, rendered as real bullets or numbered items.
- Preserved optional scoped personalization, evidence discipline, Form Lock, legal/career safeguards, lifecycle approval, and white-label output behavior.
- Kept the public Writing Kit focused on governed writing and bounded automation; long-running autonomous and marketplace-discovery systems are outside this release.
