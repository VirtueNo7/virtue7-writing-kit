# Quickstart

Download the minimal runtime ZIP, upload it to a file-capable AI, and give the task directly.

```text
Turn these notes into an article for technical readers. Keep the evidence boundary visible and do not add a takeaway list.
```

Virtue7 selects one route and profile, loads five active files, and returns a Draft. Reply with a revision instruction or `Approve`.

Use the complete source ZIP only when extending or auditing the runtime. Use the examples ZIP when learning from finished journeys.
