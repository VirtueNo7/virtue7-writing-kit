# Architecture

Virtue7 is a governed writing runtime with three operating modes: **Chat, Content, and Automation**. Mode controls lifespan; capability controls the kind of work; profile controls artifact form; tool contracts control executable external actions.

Runtime behavior begins with the three-file boot. Chat normally stops there. Content adds one route and one profile. Automation adds a compact mode packet plus only the current task, route, profile, state, or tool contract required for the active step.

Canonical taxonomies and schema validation keep identifiers, lifecycle states, gates, routes, profiles, artifacts, approvals, and receipts aligned without preloading them into ordinary work.

The central loading rule is minimum sufficiency: load the smallest packet that can complete the current step, collapse completed work into compact state, and hand that state to the next capability only when needed.

The language layer remains stable across modes. Evidence class, cadence, Form Lock, privacy scope, approval state, and tool truth travel with the work regardless of whether the user is discussing an idea, creating an artifact, or executing a bounded automation.
