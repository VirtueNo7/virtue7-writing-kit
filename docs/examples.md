# Worked examples

The library contains 35 route-conformance illustrations and 13 governance failure-and-repair examples. Every registered profile and playbook appears in the index.

Start with the [example guide](../examples/README.md) or search [`examples/index.yaml`](../examples/index.yaml) by route, profile, Form Lock, playbook, or gate.

Examples use synthetic data and remain separate from the fast runtime.
