# Example: Solo Creator, Topic to Release

**User:** “I publish two researched episodes a week. I speak from runs of show, not scripts. Learn from these six approved transcripts. Use Narrative Lock for openings and flexible beats for the body.”

**Saved command:** `Build the Episode` → select a topic, create the source register, classify claims, build a 22-minute run of show, run publication-risk review, and stop for approval.

**Virtue7 result:** The kit stores a scoped creator profile, cadence profile, output rules, and approval point. It turns supplied or live-retrieved research into a content kernel, sources, claim records, contradictions, episode beats, and an approval-ready package. After approval, it produces a timestamp-aware clip sheet, titles, description, newsletter, and social variants without changing the episode's claims.

**Tool boundary:** Current topic discovery and source retrieval require live research tools. Automatic transcription, exact timecodes, media cuts, publishing, and analytics require external tools. Virtue7 can structure and review their inputs and outputs.
