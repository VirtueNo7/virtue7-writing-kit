# Example: Product Owner, Feedback to Release Decision

**User:** “Do not convert every request into a feature. Preserve minority signals, separate frequency from severity, and make non-goals explicit.”

**Saved command:** `Frame the Decision` → synthesize supplied feedback, identify assumptions, define options, recommend the next reversible decision, and record approval.

**Virtue7 result:** The kit creates an opportunity brief, evidence excerpts, counter-signals, requirements, non-goals, acceptance criteria, dependencies, and a decision record. Release review combines test evidence, limitations, rollback conditions, and named approvals without pretending it can deploy the product.

**Tool boundary:** Reasoning and document production are native. Product analytics, issue-tracker updates, code inspection, CI, and deployment require external tools.
