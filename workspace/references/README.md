# Reference Workspace

Store project references here only when creating a working copy of the kit. Classify each source before use.

- `canonical/`: approved author positions and project truth
- `voice/`: authentic samples suitable for voice analysis
- `structural/`: organisation and pacing references
- `evidence/`: factual and documentary sources
- `inspiration/`: broad qualities only; never copy distinctive expression
- `excluded/`: materials prohibited from influencing output

Use IDs and records rather than relying on filenames alone. Do not include private project material in a public release.
