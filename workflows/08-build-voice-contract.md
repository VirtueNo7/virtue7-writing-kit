# Workflow 07 - Build the Voice Contract

## Inputs

- approved voice references;
- optional project-native samples;
- audience and format requirements;
- user corrections.

## Steps

1. Select representative creator-owned samples.
2. Identify observable behaviours, not vague adjectives.
3. Attach one or more reference IDs to each behaviour.
4. Assign confidence.
5. Identify behaviours that vary by format.
6. Record anti-patterns and phrases to avoid.
7. Translate named style requests into neutral craft qualities.
8. Draft a short voice test passage when useful.
9. Revise from user feedback.
10. Mark the contract approved before full drafting.

## Output

Use `templates/voice-contract.md`.
