# Workflow 08 - Run the Drift Test

## Purpose

Test a drafted unit before it becomes a scaling reference.

## Tests

### Meaning drift

Does the unit alter, weaken, reverse, or overstate the approved kernel or unit responsibility?

### Voice drift

Does it violate supported behaviours in the voice contract?

### Source drift

Does it introduce unsupported facts, quotations, dates, dialogue, certainty, or attribution?

### Contamination drift

Did a structural or inspirational source leak distinctive phrasing, metaphors, anecdotes, or signature construction?

### Genericity drift

Could the passage be transplanted into an unrelated AI-written book by replacing a few nouns? Flag abstract uplift, inflated conclusions, repetitive moralising, empty transitions, and ornamental certainty.

### Provenance drift

Can each material claim and major interpretive move be traced to a source, canonical dependency, or clearly labelled new interpretation?

## Result

Score each test:

- `Pass`;
- `Revise`;
- `Block`.

Any `Block` prevents promotion to project-native voice canon.
