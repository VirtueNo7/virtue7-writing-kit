# Workflow 06 - Build the Reference Library

## Trigger

Use when the user supplies existing writing, transcripts, interviews, journals, notes, research, sample chapters, or structural examples.

## Steps

1. Inventory the supplied material without drafting.
2. Ask what authority the material should have when unclear.
3. Assign stable IDs: `CAN-`, `VOI-`, `STR-`, `EVI-`, `INS-`, or `EXC-`.
4. Permit multiple functions where justified.
5. Record prohibited uses and uncertainty.
6. Identify conflicts and duplicates.
7. Create `templates/reference-register.md`.
8. Produce a compact reference map.
9. Ask for approval before using the corpus to define voice or canonical meaning.

## Minimum output

- corpus summary;
- classified register;
- authority notes;
- conflict list;
- missing material;
- proposed next step;
- approval state.

## Guardrail

Do not summarise a creator's position from an inspiration or structural source. Do not label AI-generated material as creator-authored.
