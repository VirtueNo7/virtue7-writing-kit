# Security Policy

## Supported version

Security and privacy fixes target the latest tagged release.

## Report privately

Do not open a public issue for credentials, private-data exposure, cross-scope leakage, unsafe tool execution, release-integrity problems, or other vulnerabilities that could harm users. Use GitHub's private vulnerability reporting when available.

Include the affected version, files or route, reproduction steps, expected boundary, observed behavior, and whether any real data was exposed. Use synthetic material whenever possible.

Virtue7 is a prompt-and-file runtime, not a security boundary. Host permissions, tool authorization, data retention, and professional review remain the responsibility of the environment and user.
