# Quick Commands

Start directly:

- `Write a short story from this premise`
- `Research this question and separate facts, allegations, theories, and unknowns`
- `Turn this transcript into a run of show`
- `Build a product brief from these interviews`
- `Turn this process into an SOP`
- `Review this draft for evidence, cadence drift, and publication risk`
- `Continue project`

Make the kit personal:

- `Make it mine`
- `Learn my cadence from these approved transcripts`
- `Use Narrative Lock for this project`
- `Switch to my [role, organization, client, or project] profile`
- `Make this a command called [name]`
- `Show my commands`
- `Show playbooks for [role or outcome]`

Control the work:

- `Preserve everything except the section I named`
- `Show the source behind each material claim`
- `Approve`
- `Export as [format]` when the host can create that file type

Examples such as `Find the Clips` or `Build the Case` are user-defined names, not hard-coded syntax. Commands may be added, renamed, scoped, or removed.
